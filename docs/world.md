# 세계관과 역할

> 세계관 요약, 용어집, 지명, 이용 연령, 플레이어 역할, 캐릭터 생성 항목.
> 원본은 설정집이다. 이 파일과 설정집이 다르면 설정집이 우선이다. 장 번호(4-1 등)는 파일을 나누기 전의 번호를 그대로 두어 서로 참조할 수 있게 했다.

## 2. 세계관 요약 (개발용)

### 배경

- 국가 간 전쟁 중 좀비 바이러스가 퍼졌고, 백신 개발을 계기로 임시 휴전했다. 현재는 **휴전 5년차**.
- 휴전 후 전 국민에게 백신이 투여됐고, 극소수에게서 부작용으로 이능력이 발현했다. 발현할 때 기억을 잃었다.
- 황폐 지역에는 오염이 남아 있다. 능력자는 출동하고 능력을 쓰면 몸에 오염이 쌓이고, 휴식으로 걷어낸다.
- 보조약 설정은 없다. 예전 설정 문서에 "보조약", "안정화제", "물약"이 보이더라도 쓰지 않는다.
- 휴전 1년차에 내전이 터졌고 2년차에 정부가 진압했다. 잔존 무장 세력 일부가 황폐 지역에 숨어 있다.
- 정부는 능력자를 등록·감시하며 위험한 일에 부린다. 아킬레아 재단은 능력자의 생활을 돌보며 정부와 대립한다.
- 도시는 일상을 되찾았고, 황폐 지역에는 좀비, 변이 생명체, 잔존 무장 세력이 남아 있다.

### 용어집 (UI 문구는 이 표기를 따른다)

| 용어 | 뜻 | 비고 |
| --- | --- | --- |
| 오염 | 황폐 지역 활동과 능력 사용으로 몸에 쌓이는 수치 | 시스템 기본 표기. 휴식으로 줄어든다 |
| 휴식 | 쌓인 오염을 걷어내는 행동 | 재단 시설, 의료동, 정착지에서 할 수 있다 |
| 관리대상자 | 정부가 능력자를 부르는 말 (문서상 "특이반응자") | 정부 측 공문, 명령서 문구 |
| 발현인 | 재단이 능력자를 부르는 말 | 재단 측 화면 문구 |
| 능력자 | 일반적인 호칭 | 시스템 기본 표기 |
| 백지, 실험체 | 능력자를 향한 멸칭 | **시스템 문구에서 쓰지 않는다.** 플레이어 롤플레이 안에서만 존재 |
| 아킬레아 재단 (Achillea Foundation) | 능력자 복지 재단 | |
| 황폐 지역 | 전쟁, 감염, 내전으로 버려진 땅 | 정화 작업의 무대 |
| 정화 작업 | 황폐 지역의 위협을 없애고 오염을 걷어내는 임무 | 메인 협동 콘텐츠 |
| 정착지 | 피난민들이 세운 마을 | 이름은 피난민 대표가 지었다는 설정. 플레이어가 등록 가능 |

### 지명

| 지명 | 무엇인가 |
| --- | --- |
| 오르덴 공화국 | 무대가 되는 나라. 여러 문화권의 사람이 섞여 산다 |
| 베스카르 연방 | 전쟁 상대국. 휴전 중 |
| 헤일렌 | 수도이자 회복된 대도시. 정부 기관과 재단 본부가 있다. 플레이어의 생활 거점 |
| 가람터 | 헤일렌의 구시가지. 옛말로 "강가의 터" |
| 토르빈 | 내전 격전지였던 옛 공업 도시. 지금은 황폐 지역, 잔존 무장 세력이 숨어 있다 |
| 에브론 경계지대 | 베스카르와 맞닿은 국경 지역. 변이 생명체가 가장 많은 정화 작업의 주무대 |
| 새벽뜰, 누에바 에스페란사, 스텔라 | 정착지 예시. 플레이어가 더 등록할 수 있다 |

- 지명 방식은 혼합형: 나라와 수도는 고유한 조어, 구시가지는 옛말, 피난민 정착지는 출신 언어나 바람을 담은 이름.
- 지명은 코드에 직접 박지 않고 DB나 설정값으로 둔다 (나중에 바꾸거나 늘리기 쉽게).

### 이용 연령

- **전체 이용가.** 미성년자도 함께 노는 공간이라는 전제로 모든 시스템 문구, 기본 콘텐츠, 운영 규칙을 정한다.
- 연인 관계 롤플레이는 허용하되 성적인 묘사는 이용 규칙으로 금지하고, 신고와 조치를 빠르게 한다.
- 성인과 미성년 이용자가 외부 연락처를 주고받도록 유도하는 기능은 만들지 않는다.
- **만 14세 미만 가입**: 개인정보 보호법상 만 14세 미만의 개인정보를 받으려면 법정대리인 동의가 필요하다. 보호자 동의 절차를 둘지, 가입을 만 14세 이상으로 할지 운영자가 정한다 (미정). 정해지기 전에는 가입 시 만 14세 이상 확인 항목을 둔다.


## 3. 플레이어 역할

| 역할 | 하는 일 | 받는 것 | 의무 |
| --- | --- | --- | --- |
| 능력자 | 황폐 지역 정화 작업 출동 | 능력, 재단의 생활 지원과 휴식 시설 | 정부의 출동 명령 수행 |
| 재단 직원 | 능력자의 오염 관리와 케어, 의료·상담·행정 등 | 재단의 시설과 지원 | 재단 업무 |
| 무소속 | 도시 생활자부터 여행자까지, 어디에도 매이지 않은 시민 | 없음 | 없음 |

- **능력자는 이중 소속이다.** 법적으로는 정부의 관리대상자(등록과 출동 명령), 생활은 재단(집, 치료, 휴식). 정부는 플레이어 진영이 아니라 NPC 세력이다.
- **등록을 거부한 능력자는 무소속**이 된다. 이들은 정착지에서 쉬며 오염을 걷어낸다. 가볍게 처리한다.
- 재단 직원의 직업 폭은 넓게 둔다 (의료진, 상담사, 행정직, 요리사, 정비공, 기숙사 관리인 등).

### 캐릭터 생성 시 플레이어가 고르는 것

- 역할 (능력자 / 재단 직원 / 무소속)
- 이름, 외형, 성격, 과거 (자유 서술)
- 능력자만: 능력 (자유 서술, 종류 제한 없음), 기억상실 정도 (거의 다 기억함 / 특정 시기만 빠짐 / 이름만 남음 / 전부 잊음)
- 출신 정착지 (선택, 플레이어가 새로 등록 가능)
- 능력치 배분 (4-1-1): 모든 능력치 기본 30에 배분 포인트 100을 나눠 넣는다. 생성 때는 한 능력치를 60까지만 올릴 수 있다.
- 능력자만: 발현 이전 기록 4항목 (본명, 생년, 거주지, 직업). 기억상실 정도만큼 뒤에서부터 말소된다 (거의 다 기억함: 직업 / 특정 시기만 빠짐: 거주지·직업 / 이름만 남음: 생년·거주지·직업 / 전부 잊음: 넷 모두). 남은 항목만 적을 수 있고 모두 선택이다. 말소된 항목은 입력할 수 없다. 등록 뒤에도 고칠 수 있다. (2026-11-02 정함)
- 기억상실은 능력자에게만 적용된다. 재단 직원과 무소속은 기억이 온전하다.
